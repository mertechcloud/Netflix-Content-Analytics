# Netflix Content Dataset Dictionary

This document describes the structure and column contents of the Netflix dataset.

| Column | Description |
| :--- | :--- |
| **show_id** | Unique identifier for each Netflix title |
| **type** | Indicates whether the title is a Movie or TV Show |
| **title** | Name of the content |
| **director** | Director of the title |
| **cast** | Main cast members |
| **country** | Country where the title was produced |
| **date_added** | Date the title was added to Netflix |
| **release_year** | Original release year |
| **rating** | Audience/content rating |
| **duration** | Movie length or number of TV seasons |
| **listed_in** | Genre or categories |
| **description** | Brief summary of the title |
